Outputs

Text / image → video Wan 2.2 5B · V100 B :8189
~14 s/step at 832×480×49f on this GPU. auto takes the output size from the start image (aspect kept, sides snapped to 16), so the clip frames exactly like the picture you fed it. Wan's native pass is 121 frames, so anything over 5 s renders as chained passes — each one seeded with the previous pass's last frame — and gets stitched into one mp4 (gen video --seconds 30 --plan shows the split). Editing (trim/concat/captions): vid CLI, skill studio-video-edit.
